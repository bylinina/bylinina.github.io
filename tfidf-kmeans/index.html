TF-IDF matrix

Rows = documents; columns = words. Switch between the three stages to see how the numbers are built.

k-means clustering

Each document is now a point with one coordinate per word. k-means repeats two steps: assign every document to its nearest centroid, then move every centroid to the average of its documents.

The map squeezes all word dimensions into two just for display. Distances are computed in the full space.

Centroids: the average row of each cluster

From centroids to words

A centroid has one weight per word, so sorting it gives a ranked word list. The highest weights are the most typical words. Subtracting the average document first keeps only the words that set this cluster apart.
